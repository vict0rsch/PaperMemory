# PaperMemory · store listing

## Name

PaperMemory

## Short description

Saves the research papers you open on arXiv, OpenReview and more. Search, tag, annotate and cite them from your browser.

## Full description

PaperMemory keeps a record of the research papers you read. Open a paper on a supported site and it is added to your Memory with its title, authors, venue, year, links and BibTeX. You can then search it, tag it, add a note and copy a citation, from the popup or from a full-page view.

RECORDING
• Papers are saved when you open them on arXiv, OpenReview, NeurIPS, PMLR, ACL Anthology, CVF, Nature, Science, IEEE, ACM, Springer, bioRxiv, PubMed Central and more than 15 other publishers and archives. Abstract pages and PDFs both work.
• A small notice on the page confirms the save.
• Any other web page (a blog post, a documentation page) can be added by hand from the popup.
• For arXiv preprints, PaperMemory looks for the published version on public bibliographic services such as DBLP, Semantic Scholar, CrossRef and OpenAlex, and shows the venue when it finds one.

FINDING PAPERS
• Search titles, authors and notes as you type.
• Filter by tag (t:), year (y:) or code link (c:). Filters appear as pills and combine with free text.
• Tags, a note, a code link and a favourite star on every paper.
• Sort by date added, last opened, title, year or number of visits.
• A full-page Memory with a table view, a tag list and actions on several papers at once (tag, favourite, copy BibTeX, export, delete).

CITING AND SHARING
• Copy a paper's BibTeX, Markdown link, rich link or URL with one click or one key.
• Export your Memory, or the papers with a given tag, as a .bib file.
• BibMatcher: give it a .bib file and it proposes the published version of each preprint (arXiv, bioRxiv, medRxiv, ChemRxiv). You accept or reject every change, and your citation keys can be kept.

ON PAPER PAGES
• On arXiv, a small PaperMemory block shows whether the paper is saved, with BibTeX, a Markdown link, a PDF download and the published venue.
• PDF tabs are renamed with the paper's title instead of a file name such as 1706.03762.pdf.
• PDFs can be downloaded with a readable name into a PaperMemoryStore folder in your Downloads; on arXiv, the block then shows the file in its folder.
• Open an arXiv paper on ar5iv, alphaXiv, Hugging Face or SciRate.

YOUR DATA
• Your Memory is stored in your browser's extension storage. There is no PaperMemory account and no PaperMemory server.
• No analytics, no tracking.
• To fill in a paper's details, PaperMemory sends that paper's title or identifier to academic and publication services (e.g. arXiv, CrossRef, DBLP, Semantic Scholar, OpenAlex). Your notes and tags are never sent.
• Optional sync: with a GitHub token you provide, your Memory is copied to a private Gist in your own GitHub account, so you can use it on several computers. Off by default.
• Export a full backup as JSON at any time, and import it back.

ALSO
• Keyboard shortcuts for almost everything in the popup.
• Light, dark and system themes.
• Auto-tagging rules based on title or authors.
