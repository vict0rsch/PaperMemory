# Privacy Policy

*Last updated: November 12, 2026*

## Overview

PaperMemory is a browser extension that helps you organize and remember academic papers. **PaperMemory does not collect, transmit, or store any personal information.**

## Data Storage

All data generated by PaperMemory (your paper library, notes, tags, and settings) is stored **locally** in your browser's extension storage. Your library is only uploaded to GitHub if you set up the optional GitHub Gist synchronization (see below). To look up paper metadata, PaperMemory contacts third-party services (see [Third-Party Services](#third-party-services)).

## GitHub Gist Synchronization

If you choose to set up the optional GitHub Gist sync feature, your paper library data is stored in a GitHub Gist under **your own GitHub account**. Saving your GitHub token in the options page creates a private Gist containing your current library if you don't already have one, even before you start syncing. This sync is entirely between your browser and GitHub's servers using a personal access token that you provide.

PaperMemory does not operate any server, proxy, or intermediary in this process. The extension communicates directly with GitHub's API on your behalf. Your GitHub token is stored locally in your browser's extension storage and is sent to GitHub's API to authenticate sync requests. It is never shared with the developer or any other third party.

The developer of PaperMemory has no access to your GitHub data, your token, or your synced content.

## Analytics and Tracking

PaperMemory does **not** include any analytics, telemetry, tracking pixels, or third-party scripts. No usage data is collected or transmitted.

## Third-Party Services

Besides the optional GitHub Gist sync described above, PaperMemory sends requests to academic and publication services (e.g., arXiv, CrossRef, DBLP, Semantic Scholar, Unpaywall) to fetch metadata and enrich paper information. These requests contain a paper's title or identifier (such as its DOI or arXiv id), sent as-is. Requests to CrossRef also include the PaperMemory developer's contact email (as CrossRef asks of API clients) and requests to Unpaywall include a generic placeholder email; neither is yours. Your notes, tags and the rest of your library are not included. As with any web request, these services can see your IP address.
