What’s new

2.0.0 18 Nov 2026

  • NewA new design across the extension, with a System, Light or Dark theme
  • NewRebuilt popup: t:, y: and c: filters become pills that combine with free text, tag suggestions with counts, and a ? sheet listing the keyboard shortcuts
  • NewRebuilt full-page Memory with a tag list, a sortable table, a detail pane and actions on several papers at once (tag, favourite, copy BibTeX, export, delete)
  • NewRebuilt options page on one page with a settings search and a tag manager to rename, merge and delete tags
  • NewBibMatcher now looks up bioRxiv, medRxiv and ChemRxiv preprints as well as arXiv; you accept or reject each change, and the rest of your .bib file is kept as is
  • NewA compact PaperMemory block on arXiv pages, and an on-page notice when a paper is saved, with Undo
  • NewA welcome tab on first install to test the shortcut, pick your sources and choose a theme
  • NewNew icon, and the extension is now named PaperMemory
  • DevAll Memory changes go through one queue in the background, so open pages no longer overwrite each other
  • DevFix finding the published version of preprints: DBLP is queried through SPARQL and OpenAlex replaces Unpaywall
  • DevFix Gist sync after the browser restarts the background worker, with uploads that no longer overlap
  • RemovedThe remaining requests to Papers with Code, which no longer exists
