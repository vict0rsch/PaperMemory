Import & export

with their tags, notes and code links. “Memory” is the full backup (.json).

Export by tag

Papers that have of these tags.

Import papers from URLs

A .json list of paper URLs or DOIs, optionally with tags and a code link. Papers are fetched one at a time.

See the format

A list where each entry is a paper URL (PDF or abstract page, from a supported source), a DOI (10.…, doi:10.… or a doi.org URL, read from the publisher's page it leads to), or an object with a url and, optionally, codeLink and tags. With Sync on, the gist is updated once every paper is imported. 

[
  "https://arxiv.org/abs/2110.02871",
  {
    "url": "https://openreview.net/forum?id=xQUe1pOKPam",
    "codeLink": "https://github.com/chao1224/graphmvp",
    "tags": ["graphs", "molecules"]
  }
]

    GitHub Gist

    Keeps one private gist up to date so you can use PaperMemory on several computers, one at a time. Edits made at the same moment on two computers are not merged.

    Not connected
    Needs the “gist” scope only. Your token is stored in this browser's extension storage and only sent to GitHub's API. Saving a token creates a private Gist containing your Memory if you don't already have one. Create a token

    Agent access

    Local AI agents

    Lets AI agents running on this computer, such as Claude Code, Codex, Cursor, OpenCode or Oh-My-Pi, search your Memory and add papers to it. Papers an agent adds get the review tag.

    Agent tools
    Install them once with npx -y papermemory-mcp install, then turn Agent access on. The first time an agent asks for access, PaperMemory opens this page so that you can allow or deny it.
