Import papers from URLs

A .json list of paper URLs, optionally with tags and a code link. Papers are fetched one at a time.

See the format

A list where each entry is a paper URL (PDF or abstract page, from a supported source) or an object with a url and, optionally, codeLink and tags. With Sync on, the gist is updated once every paper is imported.

  "https://arxiv.org/abs/2110.02871",

    "codeLink": "https://github.com/chao1224/graphmvp",
    "tags": ["graphs", "molecules"]
  }

    GitHub Gist

    Keeps one private gist up to date so you can use PaperMemory on several computers, one at a time. Edits made at the same moment on two computers are not merged.

    Not connected
